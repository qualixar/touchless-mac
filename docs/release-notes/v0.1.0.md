The first release of **touchless-mac**: control your Mac with your hand through the built-in camera. Everything runs on your Mac; nothing is sent anywhere.

**What your hand can do:** point to move the cursor, pinch to click, pinch twice to double-click, pinch thumb and middle finger to right-click, touch thumb to ring finger and move to scroll, and wave to switch apps or open Mission Control.

**Install from source (recommended):**

```sh
git clone https://github.com/qualixar/touchless-mac.git
cd touchless-mac
bash scripts/get-models.sh
cargo run --release
```

**Or use the ready-made Apple Silicon build** attached below. It isn't signed by an Apple developer account yet, so macOS quarantines it. After unpacking, run `xattr -dr com.apple.quarantine touchless-mac-v0.1.0-macos-arm64`, then `bash scripts/get-models.sh` and `./touchless-mac` inside the folder.

See the [README](https://github.com/qualixar/touchless-mac#readme) for gestures, calibration and options, and [CHANGELOG.md](https://github.com/qualixar/touchless-mac/blob/main/CHANGELOG.md) for details. If it works for you, a star helps other people find it.
