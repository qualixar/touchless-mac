**touchless-mac 0.1.1** makes setup feel like a finished product: one command installs it, the hand models come in the box, and `touchless-mac doctor` tells you exactly what's left to switch on.

**Install (Apple Silicon Mac):**

```sh
curl -fsSL https://raw.githubusercontent.com/qualixar/touchless-mac/main/install.sh | bash
touchless-mac doctor
touchless-mac
```

or `brew install qualixar/tap/touchless-mac`.

**What's new**

- One-line installer: downloads this release, checks the SHA-256 fingerprint, installs to `~/.local`, no `sudo`.
- The two hand models are included in the download (Apache 2.0, unchanged; see `models/NOTICE.md`).
- The app finds its models from any folder, and lists every place it looked if they're missing.
- `touchless-mac doctor` checks models, camera, Accessibility and calibration.
- A missing permission opens the right page of System Settings for you.
- `--version`, a corrected hint in `get-models.sh`, and contributing, security and conduct files.

**Learning Rust with it?** The full video tutorial builds this app from an empty folder: https://youtu.be/ml6cmS3Jgkc. The chapter tags `ch1-cargo` to `ch6-calibrate` are unchanged.

The build isn't signed by an Apple developer account yet. The installer and Homebrew handle that; if you download the archive in a browser, run `xattr -dr com.apple.quarantine <folder>` after unpacking. Tested on Apple Silicon (M5 Pro); Intel untested (build from source).
