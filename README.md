# touchless-mac

Control your Mac with your hand, built one Rust idea at a time. This is the code from the
YouTube tutorial "Learn Rust by building a touchless Mac".

This is chapter 1 (`ch1-cargo`): Cargo and crates. The app opens your camera and counts pictures.
Later tags add the cursor, gestures, error messages and calibration; the final README lives on the last tag.

    cargo run --release
    cargo run --example 01_cargo
